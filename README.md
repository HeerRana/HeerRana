## 🔬 Research Experience

### Skin Cancer Detection Using Deep Learning

**Research Intern — Adani University | June 2026 – July 2026**

- Developed a deep learning pipeline for seven-class skin lesion classification using the HAM10000 dataset containing 10,015 dermoscopic images.
- Implemented image preprocessing with Gaussian filtering and CLAHE contrast enhancement.
- Conducted experiments using Focal Loss, MixUp augmentation, and early stopping.
- Benchmarked ResNet50 against ViT-B/16 for classification performance.
- Achieved 84% peak accuracy and a Macro F1 score of 0.73 with ResNet50 in the reported experiments.

**Research Areas:** Python · Deep Learning · Computer Vision · Image Processing · TensorFlow · Model Evaluation
